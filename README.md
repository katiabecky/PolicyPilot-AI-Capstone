# PolicyPilot AI Capstone

PolicyPilot AI is a solo capstone project that builds a retrieval-augmented policy assistant for company documents.

## Project Goal
The system will allow users to ask policy-related questions in natural language and receive grounded answers with citations from approved source documents.

## Planned Structure
- app/ : Streamlit application
- data/ : policy documents and processed chunk data
- scripts/ : ingestion, chunking, and retrieval scripts
- tests/ : validation and test files
- .github/workflows/ : CI workflow files
